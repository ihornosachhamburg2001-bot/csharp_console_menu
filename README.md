# CSharp Console Menu

A console application written in C# that demonstrates how to create an interactive menu in the terminal.

## About the Project

**CSharp Console Menu** is a simple C# project designed to practice programming fundamentals and console application development.

The project provides a starting point for implementing menu navigation and handling user input in a console environment.

## Features

- Interactive console menu
- User input handling
- Console-based navigation
- C# programming practice

## Technologies

- **Language:** C#
- **Platform:** .NET
- **IDE:** Visual Studio

## Getting Started

### Prerequisites

- Visual Studio with the .NET development workload installed
- A compatible .NET SDK

### Run the Project

1. Clone the repository:

   ```bash
   git clone https://github.com/ihornosachhamburg2001-bot/csharp_console_menu.git
   ```

2. Open the `.sln` solution file in Visual Studio, or open the project file (`.csproj`).

3. Build and run the application using Visual Studio.

## Project Structure

The project contains the C# source code and configuration files required to build and run the console application.
